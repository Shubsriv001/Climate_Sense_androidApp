## 📸 App Overview

Climate Sense is a weather and climate-focused Android app that provides real-time data, AI-powered insights, and user-friendly features. Below are the core screens and components of the app:

### 🧭 Screens & Features:

- ✅ Onboarding Screens  
- 🔐 Login & Signup  
- 📱 Phone Authentication  
- 🔁 Forgot Password  
- 🏠 Home Screen (Weather Dashboard)  
- 🔍 Searched Weather Screen  
- ℹ️ About App  
- 📰 Climate News  
- 🗣️ Feedback Section  
- 📄 Terms and Conditions  
- 🛠️ Support / Help  
- 👤 Profile Management  
- 🤖 AI-Powered Climate Chat

## 🧑‍💻 Technologies Used

The Climate Sense app is built using:

- **Kotlin** – for native Android development  
- **Android Studio** – as the development environment  
- **OpenWeather API** – for real-time weather data  
- **Supabase** – for phone authentication and database  
- **Material Design** – for modern UI  
- **OpenAI API** – for AI chat feature
- **G news API** – for news
